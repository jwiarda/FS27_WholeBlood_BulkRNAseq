# FS27_WholeBlood_BulkRNAseq

Differential gene expression analysis of whole blood RNA-seq samples derived from Salmonella-infected or control pigs at 2 and 8 days post-infection.

Target file = sample key and metrics of read processing.

## some components of analysis were performed specifying 2 or 7 days post-infection as timepoints used. 7 days post-infection is incorrect and was changed to the correct timepoint of 8 days post-infection for publication.
